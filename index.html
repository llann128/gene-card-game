你是基因小博士

你要帮助小动物选择合适的基因，把它们改造成更强、更适合环境的超级生物。

🃏

认识四种卡牌

生物载体卡 小动物，有基础分
基因片段卡 增强能力，需适配环境
特殊卡牌 每局最多1张
环境卡 决定对战环境
🔗

什么是适配

基因必须适配生物的环境才生效。水中基因装给陆地动物不会生效。

🔄

一局怎么玩

翻环境卡 → 选生物 → 装基因 → 用特殊卡 → 亮牌 → 算分

🧮

怎么算分

总分 = 基础分 + 基因攻击 + 环境加成 + 特殊卡 − 对手抵消

🗑️

弃牌规则

用过的卡牌进入弃牌堆，后续局数不能再使用。
